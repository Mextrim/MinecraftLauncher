# 💜 Mex Launcher — Сделано с любовью специально для моих друганов

Эксклюзивный, современный и быстрый лаунчер для Minecraft, написанный на **Java** и запускаемый через нативный Windows **`.exe`**.

Специально собран для максимального кайфа и стабильной игры с друзьями: чистая нативная среда, готовая сборка модов **YOLO (53 мода)**, полноценная **Студия скинов** с предпросмотром персонажа и умная оптимизация памяти без лагов.

---

## 🚀 Быстрый запуск

### 1. Нативный Windows EXE (Рекомендуется)
Дважды кликните по файлу:
👉 **[`MexLauncher.exe`](MexLauncher.exe)** *(или [`MinecraftLauncher.exe`](MinecraftLauncher.exe))*  
*(также доступен [`run.bat`](run.bat))*

- Мгновенный запуск без черных консольных окон.
- Автоматически находит установленную Java (Adoptium Temurin 17 / 21 / 25, Microsoft OpenJDK, Oracle).
- Полная совместимость со сборкой YOLO 1.20.1 Forge на Java 17.

### 2. Универсальный кроссплатформенный JAR
👉 **[`Launcher.jar`](Launcher.jar)**  
Запуск кликом или через терминал:
```cmd
java -jar Launcher.jar
```

## ✨ Главные фишки и возможности

### 🧍‍♂️ Студия персонажа и скинов (Skin Studio)
- **2D-подиум с моделью персонажа**: отображение 2D-модели игрока (голова, тело, руки, ноги, объёмный слой волос и одежды, тень и бейдж).
- **Коллекция готовых скинов в 1 клик**:
  - *Стив (Классический)*
  - *Алекс (Классическая)*
  - *Крипер в худи*
  - *Киберпанк (Неон)*
  - *Военный SWAT*
  - *Тёмный ассасин*
- **Свой скин (.PNG)**: кнопка выбора любого файла скина через проводник.
- **Загрузка по нику Mojang**: загрузка скина любого лицензионного игрока (Notch, Dream, MrBeast и др.).
- **MEX SkinPack**: скин автоматически компилируется в ресурспак и активируется в игре — отображается как в одиночной игре, так и на серверах!

### 💥 Предустановленная сборка YOLO (53 мода)
- Современный огнестрел **TACZ** с кастомной физикой и прицелами.
- Хоррор-двеллеры (*The Man from the Fog*, *Cave Dweller*, *The Knocker*).
- Данжи и структуры *YUNG's*.
- Графика и шейдеры *Oculus* + оптимизация *Embeddium*.
- Голосовой чат *Plasmo Voice*.

### ⚡ Оптимизация и пресеты RAM
- Кнопки быстрого выбора памяти во вкладке «Настройки»:
  - **4 ГБ** — для ванильного клиента.
  - **6 ГБ (Топ для YOLO)** — золотой стандарт для модпака.
  - **8 ГБ (Мощный)** — для шейдеров и ультра-прорисовки.
  - **12 ГБ / 16 ГБ** — экстремальный режим.
- Оптимизированные флаги **Aikar's G1GC** для исключения фризов сборщика мусора.

### 🎨 5 неоновых тем оформления
- 🌿 **Изумруд** (Emerald)
- 💎 **Алмаз** (Diamond)
- 🔮 **Аметист** (Amethyst)
- ⚔️ **Незерит** (Netherite)
- 🔴 **Редстоун** (Redstone)

### 📂 Быстрый доступ в 1 клик
- Кнопки мгновенного открытия папок: `.minecraft`, `mods/` (моды), `shaderpacks/` (шейдеры), `resourcepacks/` (ресурспаки).

## 🛠️ Сборка из исходников

Для пересборки проекта в 1 клик запустите:
👉 **[`build.bat`](build.bat)**

Скрипт автоматически компилирует Java-классы, запаковывает `Launcher.jar` с шрифтами FontAwesome и компилирует нативные `MexLauncher.exe` и `MinecraftLauncher.exe`.

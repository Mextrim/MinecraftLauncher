# 💜 Mex Launcher — Сделано с любовью специально для моих друганов

Эксклюзивный, современный и быстрый лаунчер для Minecraft, написанный на **Java** и запускаемый через нативный Windows **`.exe`**.

Вся экосистема лаунчера синхронизирована с **GitHub**: `MexLauncher.exe` и `MexLauncher.java` автоматически подкачивают все необходимые данные, моды, библиотеки и скины напрямую из репозитория GitHub.

---

## 🚀 Основные файлы проекта

1. 👉 **[`MexLauncher.exe`](MexLauncher.exe)** — Нативный Windows EXE.
   - Запускается мгновенно без консольных окон.
   - **Авто-подкачка с GitHub**: если запущен отдельно без JAR, автоматически загружает ядро лаунчера с GitHub с красивым индикатором прогресса!
   - Автоматически находит установленную Java 17+ или предлагает настроить Adoptium JRE 17 в 1 клик.
2. 👉 **[`MexLauncher.java`](MexLauncher.java)** — Главный исходный файл лаунчера на Java.
3. 👉 **[`MexLauncher.jar`](MexLauncher.jar)** / **[`Launcher.jar`](Launcher.jar)** — Скомпилированное Java-ядро.

---

## 🌐 Автоматическая подкачка данных с GitHub

`MexLauncher` полностью автономен и скачивает все компоненты из GitHub:
- 💥 **Сборка модов YOLO (53 мода)**: загружается и распаковывается напрямую из релизов GitHub (`yolo.zip`).
- 🔨 **Forge 1.20.1 Runtime**: библиотеки и среда Forge подкачиваются из релизов GitHub (`forge-1.20.1-runtime.zip`).
- ☕ **Adoptium Java 17**: автоматическая загрузка нативного JRE 17 для бесперебойного запуска модов.
- 🔄 **GitHub Cloud Sync**: динамическая проверка свежих версий и ассетов через GitHub API.

## ✨ Главные фишки и возможности

### 🧍‍♂️ Студия персонажа и скинов (Skin Studio)
- **2D-подиум с моделью персонажа**: интерактивный 2D-рендер скина (голова, тело, руки, ноги, одежда и волосы, тень на подиуме).
- **Коллекция готовых скинов в 1 клик**:
  - *Стив (Классический)*
  - *Алекс (Классическая)*
  - *Крипер в худи*
  - *Киберпанк (Неон)*
  - *Военный SWAT*
  - *Тёмный ассасин*
- **Свой скин (.PNG)**: кнопка выбора любого скина с компьютера.
- **Загрузка по нику Mojang**: скачивание скина любого лицензионного игрока (Notch, Dream, MrBeast и др.).
- **MEX SkinPack**: скин компилируется в ресурспак и активируется в игре автоматически.

### 💥 Предустановленная сборка YOLO (53 мода)
- Огнестрельное оружие **TACZ** с кастомной анимацией и физикой.
- Хоррор-двеллеры (*The Man from the Fog*, *Cave Dweller*, *The Knocker*).
- Данжи и подземелья *YUNG's*.
- Графика и шейдеры *Oculus* + ускорение *Embeddium*.
- Голосовой чат *Plasmo Voice*.

### ⚡ Оптимизация памяти (RAM)
- Кнопки быстрого выбора RAM в «Настройках»:
  - **4 ГБ** — базовый режим.
  - **6 ГБ (Топ для YOLO)** — рекомендовано для сборки.
  - **8 ГБ (Мощный)** — для ультра-шейдеров.
  - **12 ГБ / 16 ГБ** — для стримов и максимальной графики.
- Оптимизированные флаги **Aikar's G1GC** для плавной игры без лагов сборщика мусора.

## 🛠️ Сборка из исходников

Запустите:
👉 **[`build.bat`](build.bat)**

Скрипт автоматически:
1. Компилирует классы `MexLauncher.java` и `src/com/craftlauncher/*.java`.
2. Собирает `MexLauncher.jar` со шрифтами FontAwesome 6 Solid.
3. Компилирует `MexLauncher.exe` с поддержкой автоматической загрузки компонентов с GitHub.
